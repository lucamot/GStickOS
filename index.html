what is this

One job, done right: boot straight into RetroArch.

GStickOS is a custom firmware/image for Game Stick 4K Lite that allows you to play retro games using RetroArch. The system is designed to boot directly into RetroArch, providing a seamless gaming experience.

spec sheet

Everything you need. Nothing you have to manage.

Boots into RetroArch

Boots directly into RetroArch for an instant gaming experience.

USB storage

Supports external USB storage for adding game ROMs.

~50 Libretro cores

Includes around 50 Libretro cores, with the ability to add more.

SSH enabled

SSH server enabled for remote access.

WiFi via dongle

Supports WiFi connectivity via an external USB WiFi dongle.

No copyrighted files

No ROMs or copyrighted materials are included.

install — 3 steps
  1. 1
    Download GStickOS image and unzip it.
  2. 2
    Flash the image to an SD card with Win32 Disk Image or similar.
  3. 3
    Put the SD on your Game Stick Lite 4K and start playing!
GET THE IMAGE Image > 2 GB · SD card will be wiped when flashing — no turning back!
keep it running

Made by one person, for the community.

GStickOS is a personal project — built from scratch, from the base OS (BusyBox) to RetroArch and its cores. If it saves your evening, the best thanks is a small one.

Source & toolchain

Everything is built from a custom toolchain. The docker image with the full build environment is on GitHub — recompile the whole thing, kernel included.
